# Project Standards

- Jetpack Compose with Material 3
- M3 dynamic color and accessible contrasts
- Room Database with Kotlin Coroutines & Flow
- Clean MVVM architecture (Repository -> ViewModel -> UI)
- Unique testTag on all key UI elements (e.g. `add_note_fab`, `search_input`, `note_card_1`, `save_note_button`)
- String resources defined in `strings.xml`
- Strict 48dp minimum touch targets
